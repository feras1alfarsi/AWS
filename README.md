التوثيق التقني لمشروع "مُيسّر" (Mousser)
نظام ذكاء اصطناعي لتبسيط الخطابات والمعاملات الرسمية
1. نظرة عامة (Executive Summary)
"مُيسّر" هو تطبيق سحابي متطور يهدف إلى سد الفجوة بين لغة الخطابات الرسمية المعقدة وفهم المواطن العادي. يستخدم النظام تقنيات الرؤية الحاسوبية (Computer Vision) والذكاء الاصطناعي التوليدي (Generative AI) لتحويل صور المستندات إلى ملخصات نصية مبسطة ومخرجات صوتية تفاعلية.

2. الهندسة المعمارية للنظام (System Architecture)
يعتمد المشروع على معمارية خالية من الخوادم (Serverless Architecture) بالكامل على سحابة AWS، مما يضمن القابلية للتوسع (Scalability) والكفاءة في التكلفة.
المكونات الرئيسية:
•	الواجهة الأمامية (Frontend): تطبيق مبني باستخدام إطار عمل Streamlit، يوفر واجهة بسيطة لرفع الملفات وعرض النتائج.
•	طبقة التخزين (Storage): Amazon S3 لاستضافة الصور المرفوعة والملفات الصوتية المنتجة.
•	طبقة المعالجة (Compute): AWS Lambda التي تعمل كمنسق (Orchestrator) لتدفق البيانات بين جميع الخدمات.
•	محرك استخراج النصوص (OCR): Amazon Textract لتحليل الصور واستخراج النصوص العربية بدقة.
•	محرك الذكاء الاصطناعي (LLM): Amazon Bedrock (Claude 3 Haiku) لمعالجة اللغة الطبيعية وتبسيط النص.
•	محرك التحويل الصوتي (TTS): Amazon Polly (Hala Voice) لتوليد مخرجات صوتية طبيعية.
________________________________________
3. تدفق البيانات (Data Workflow)
1.	المرحلة الأولى (الإدخال): يقوم المستخدم برفع صورة الخطاب (JPG/PNG). يتم تخزينها في S3 Bucket ويتم تحفيز دالة Lambda تلقائياً.
2.	المرحلة الثانية (التعرف الضوئي): تقوم Lambda بإرسال مرجع الصورة إلى Textract. تقوم الخدمة بإعادة النص المستخرج على شكل كتل نصية (Text Blocks).
3.	المرحلة الثالثة (المعالجة اللغوية): يمر النص المستخرج إلى Bedrock مع "أمر هندسي" (System Prompt) متخصص لتحويل اللغة الرسمية إلى لهجة بيضاء مبسطة، مع استخراج الطلبات والتواريخ.
4.	المرحلة الرابعة (التوليد الصوتي): يتم إرسال النص المبسط إلى Polly باستخدام المحرك العصبي (Neural Engine) لتوليد ملف صوتي MP3 يحاكي النبرة السعودية.
5.	المرحلة الخامسة (المخرجات): يتم تخزين الملف الصوتي في S3، وتوليد رابط مؤقت (Pre-signed URL)، وإرسال حزمة النتائج النهائية (JSON) إلى الواجهة الأمامية للعرض.

4. التفاصيل التقنية والإعدادات (Technical Specifications)
هندسة الأوامر (Prompt Engineering):
تم تصميم الأمر البرمجي ليكون مقيداً بالسياق السعودي:
"أنت مساعد ذكي لتبسيط المعاملات الحكومية السعودية. قم بتلخيص النص التالي بلهجة بيضاء وبسيطة (وش السالفة؟)، استخرج الطلبات المحددة، التواريخ، والخطوة القادمة (أبشر، ناجز، إلخ)."
إعدادات الأمان (Security & IAM):
تم تطبيق مبدأ "الأقل صلاحية" (Principle of Least Privilege) عبر إعداد سياسات IAM مخصصة للدالة:
•	AmazonS3FullAccess (للقراءة والكتابة).
•	AmazonTextractFullAccess (لتحليل المستندات).
•	AmazonBedrockFullAccess (لاستدعاء النماذج).
•	AmazonPollyFullAccess (لتوليد الصوت).

5. واجهات برمجة التطبيقات (APIs used)
•	Boto3 SDK: المكتبة الأساسية للربط بين Python وخدمات AWS.
•	Anthropic Claude Messages API: للتواصل مع نموذج Claude 3 داخل بيئة Bedrock.
•	S3 Pre-signed URLs: لتوفير وصول آمن ومؤقت للملفات الصوتية.
________________________________________
6. الرؤية المستقبلية (Roadmap)
•	RAG Integration: ربط النظام بقاعدة بيانات الأنظمة واللوائح الحكومية لتوفير شروحات قانونية أكثر دقة.
•	Multi-language Support: دعم ترجمة الخطابات فورياً للمقيمين غير الناطقين بالعربية.
•	Mobile App: إطلاق تطبيق هاتف محمول يدعم الكاميرا مباشرة للمعالجة اللحظية.

7. الخاتمة
يعد مشروع "مُيسّر" نموذجاً تطبيقياً لكيفية استغلال الذكاء الاصطناعي التوليدي في تحسين جودة الحياة الرقمية، وتحقيق أهداف التحول الرقمي ضمن رؤية المملكة 2030 من خلال تبسيط التفاعل بين الجهات التنظيمية والمستفيدين.
